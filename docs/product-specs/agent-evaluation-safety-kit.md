# Product Specification: AI Agent Evaluation & Safety Kit

- **Existing slug:** `agent-eval-harness`
- **Version:** 1.0
- **Price:** $49 one-time
- **Delivery:** One Markdown workbook rendered after purchase and downloadable as `.md`
- **Primary buyer:** Small team operating or preparing to operate an AI agent workflow
- **Primary SEO support:** `/knowledge/evaluating-agents-evals`
- **Learning path:** `/paths/evaluate-your-agent`

## Product promise

Give a small team a complete, provider-neutral operating workbook for defining success, building representative cases, grading observable behavior, documenting safety boundaries, comparing changes, and making a recorded release decision.

## Included assets inside the workbook

1. Evaluation charter
2. Workflow and action-boundary map
3. Failure taxonomy and risk register
4. Golden-set case template
5. Deterministic-check inventory
6. Human and model-grader rubric
7. Evaluation run sheet and metric formulas
8. Risk-based release gate
9. Regression and change log
10. Production sampling and incident worksheets
11. Copy-ready CSV headers
12. Fictional worked example

## Explicit exclusions

- No hosted evaluation runner
- No executable code repository
- No provider API credits or accounts
- No automatic CI/CD integration
- No guarantee that an agent is safe, accurate, compliant, or ready for production
- No legal, security, privacy, financial, or regulatory advice
