# Typography

The live font setup is defined in `src/styles.css`.

## Fonts

| Role    | Font          | Token            | Weights Imported   |
| ------- | ------------- | ---------------- | ------------------ |
| Display | Space Grotesk | `--font-display` | 400, 500, 600, 700 |
| Body/UI | Inter         | `--font-sans`    | 400, 500, 600      |

## Usage

Use Space Grotesk for:

- H1-H4 headings
- Brand-forward section titles
- High-level editorial moments

Use Inter for:

- Body copy
- Navigation
- Buttons and forms
- Metadata, labels, helper text, and dense UI

## Type Rules

- Keep global heading letter spacing at `0`.
- Do not scale font size directly with viewport width.
- Use small uppercase labels only when they behave like section labels, not decorative badges.
- Keep button and form text code-native and readable.
- Avoid overly futuristic or gimmicky type treatments; the brand should feel premium and practical.
